# PizzaBox

> A full-stack mobile food ordering platform built for real-world pizza delivery operations.

PizzaBox is a production-oriented mobile application designed around a complete food ordering workflow — from customer discovery and location-based delivery to cart management, payments, order processing, and administration.

The platform provides dedicated experiences for **Customers** and **Administrators**, with Supabase powering the backend infrastructure and Stripe handling online payments.
